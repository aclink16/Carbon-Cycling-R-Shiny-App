# Carbon-Cycling-R-Shiny-App
This model is an educational R Shiny app for exploring carbon cycling in terrestrial forests through an interactive simulation. Students can modify the environmental conditions and carbon cycle parameters to observe how these changes affect carbon pools and fluxes over time. This app is intended for use as an educational model only. It simplifies several ecological processes and should not be interpreted as a detailed carbon model. 

If you are an instructors who wishes to edit the application to represent a local terrestrial forest ecosystem, please read the instructor notes commented in the code.
