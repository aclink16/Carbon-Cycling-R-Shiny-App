# Carbon-Cycling-R-Shiny-App
This repository contains an educational R Shiny app for exploring carbon cycling in terrestrial forests through an interactive simulation. Students can modify the environmental conditions and carbon cycle parameters and observe the effects on carbon pools and fluxes over time. This app is intended for use as an educational model only. It simplifies several ecological processes and should not be interpreted as a detailed carbon model. 

About the model:
The model represents three major carbon pools:
1. Atmosphere
2. Land biota
3. Soil

It also represents how carbon moves among pools through three major carbon fluxes:
1. Photosynthesis
2. Respiration
3. Decomposition

The default parameters are based on conditions representing forests at the UW-Madison Arboretum. Instructors who wish to adapt the app to represent a local terrestrial forest ecosystem can modify the model parameters and assumptions in the R code. Instructor notes are included throughout the commented code.
